# 去重功能测试指南

## 🧪 测试场景

### 1. 数据解析去重测试 ✅

**测试数据**: `words.md` 文件中现在包含重复的单词：

-   `hello` - 出现 2 次（保留最新版本）
-   `beautiful` - 出现 2 次（保留最新版本）

**测试步骤**:

1. 重新加载插件或重启 Obsidian
2. 观察控制台输出（F12 开发者工具）
3. 查看弹窗提示信息

**预期结果**:

-   控制台显示详细的重复统计信息
-   弹窗提示：`⚠️ 发现重复单词: "hello", "beautiful"。已自动去重，保留了最新版本。`
-   最终只保留每个单词的最后出现版本

### 2. 前端添加去重测试

**测试步骤**:

1. 点击"添加新单词"按钮
2. 尝试输入已存在的单词名称（如：`hello`）
3. 点击添加按钮

**预期结果**:

-   输入框变红边框
-   显示错误提示：`⚠️ 单词 "hello" 已存在，请使用不同的名称`
-   无法提交表单

### 3. 编辑重命名去重测试

**测试步骤**:

1. 编辑某个单词（如：`world`）
2. 将名称改为已存在的单词（如：`hello`）
3. 尝试保存

**预期结果**:

-   输入框变红边框
-   显示错误提示：`⚠️ 单词 "hello" 已存在，请使用不同的名称`
-   无法提交表单

### 4. 正常编辑测试

**测试步骤**:

1. 编辑某个单词，修改其他信息（发音、分类等）
2. 不修改单词名称
3. 保存

**预期结果**:

-   正常保存，无错误提示
-   数据正确更新

## 🛠️ 重置测试环境

如需重置测试环境，删除 `words.md` 中的重复单词：

1. 移除第二个 `hello` 条目
2. 移除第二个 `beautiful` 条目
3. 重新加载插件
