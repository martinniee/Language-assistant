# 删除按钮功能测试指南

## 功能说明

我已经为编辑/添加页面的表单添加了删除按钮功能，现在每个层级都有对应的删除按钮：

### 1. 词性层级删除

-   **位置**: 每个词性部分的右上角
-   **条件**: 只有当词性数量大于 1 时才显示删除按钮
-   **样式**: 红色背景的"删除词性"按钮
-   **功能**: 删除整个词性部分及其所有定义和例句

### 2. 定义层级删除

-   **位置**: 每个定义输入框的右侧
-   **条件**: 只有当定义数量大于 1 时才显示删除按钮
-   **样式**: 小的红色"删除"按钮
-   **功能**: 删除该定义及其所有例句

### 3. 例句层级删除

-   **位置**: 每个例句输入框的右侧
-   **条件**: 任何时候都显示删除按钮（没有最少数量限制）
-   **样式**: 很小的红色"×"按钮
-   **功能**: 仅删除该例句

## 测试步骤

### 测试准备

1. 打开 Obsidian
2. 确保 Language Assistant 插件已启用
3. 打开插件面板

### 测试词性删除功能

1. 点击"添加新单词"
2. 填写基本信息（单词名称等）
3. 点击"添加词性"按钮添加第二个词性
4. 验证第一个词性部分现在显示"删除词性"按钮
5. 点击其中一个"删除词性"按钮
6. 确认该词性部分被完全删除
7. 验证只剩一个词性时，删除按钮消失

### 测试定义删除功能

1. 在一个词性中点击"添加定义"按钮添加第二个定义
2. 验证第一个定义现在显示"删除"按钮
3. 点击其中一个"删除"按钮
4. 确认该定义及其例句被删除
5. 验证只剩一个定义时，删除按钮消失

### 测试例句删除功能

1. 在一个定义中点击"添加例句"按钮
2. 验证每个例句都有"×"删除按钮
3. 点击其中一个"×"按钮
4. 确认该例句被删除
5. 验证即使只剩一个例句，删除按钮仍然显示

### 测试边界情况

1. 创建一个只有一个词性、一个定义、一个例句的单词
2. 验证只有例句显示删除按钮
3. 删除例句后验证表单仍然正常工作
4. 保存单词并验证数据正确保存

## 技术实现

### 新增的删除函数

```typescript
const handleRemovePart = useCallback((partIndex: number) => {
    setForm((f) => {
        const content = [...f.content];
        content.splice(partIndex, 1);
        return { ...f, content };
    });
}, []);

const handleRemoveDefinition = useCallback(
    (partIndex: number, defIndex: number) => {
        setForm((f) => {
            const content = [...f.content];
            content[partIndex].definitions.splice(defIndex, 1);
            return { ...f, content };
        });
    },
    [],
);

const handleRemoveExample = useCallback(
    (partIndex: number, defIndex: number, exIndex: number) => {
        setForm((f) => {
            const content = [...f.content];
            content[partIndex].definitions[defIndex].examples.splice(
                exIndex,
                1,
            );
            return { ...f, content };
        });
    },
    [],
);
```

### UI 改进

-   所有删除按钮都采用统一的红色主题样式
-   按钮大小根据层级递减（词性 > 定义 > 例句）
-   添加了 hover 提示文本
-   实现了条件显示逻辑，防止用户删除所有内容

## 预期效果

使用这些删除按钮，用户现在可以：

1. 灵活地管理单词的词性结构
2. 快速删除不需要的定义
3. 轻松移除错误或多余的例句
4. 提高编辑效率，减少重新输入的需要

这些功能与现有的添加按钮配合，为用户提供完整的 CRUD 操作体验。
