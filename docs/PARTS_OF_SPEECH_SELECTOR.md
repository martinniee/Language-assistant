# 词性选择器功能说明

## 🎯 新功能概述

为单词管理表单添加了智能的词性选择功能，用户无需手动输入，可以通过预定义选项进行快速选择。

## ✨ 功能特点

### 1. **预定义词性选项**

提供 15 种常用英语词性选项：

-   名词
-   动词
-   形容词
-   副词
-   介词
-   代词
-   连词
-   感叹词
-   助动词
-   情态动词
-   数词
-   冠词
-   不定式
-   动名词
-   分词

### 2. **词性概述 - 多选模式**

在表单顶部的"词性概述"字段中：

#### 功能特点：

-   ✅ **可视化选择** - 点击按钮快速添加词性
-   ✅ **多选支持** - 支持选择多个词性（如：名词,动词）
-   ✅ **标签显示** - 选中的词性以蓝色标签形式显示
-   ✅ **快速移除** - 点击标签上的 "×" 快速移除
-   ✅ **状态指示** - 已选词性显示 "✓" 标记
-   ✅ **空状态提示** - 未选择时显示友好提示

#### 界面布局：

```
词性概述:
┌─────────────────────────────────────┐
│ [名词 ×] [动词 ×] [形容词 ×]        │  ← 已选词性标签
└─────────────────────────────────────┘
[名词 ✓] [动词 ✓] [形容词 ✓] [副词] [介词] ...  ← 选择按钮
```

### 3. **详细内容 - 单选模式**

在详细内容的每个词性部分中：

#### 功能特点：

-   ✅ **下拉选择** - 清晰的下拉菜单选择
-   ✅ **单词性选择** - 每个部分只能选择一个具体词性
-   ✅ **默认提示** - "请选择词性" 作为默认选项
-   ✅ **标准化输入** - 确保词性名称的一致性

#### 界面样式：

```
词性: [请选择词性 ▼]
      └─ 名词
         动词
         形容词
         ...
```

## 💡 用户体验提升

### 操作便捷性

1. **快速选择** - 无需手动输入，点击即选
2. **错误预防** - 避免词性名称拼写错误
3. **标准化** - 确保词性术语的统一性
4. **直观反馈** - 选中状态清晰可见

### 多场景适配

1. **概述层级** - 适合快速标记单词的所有词性
2. **详细层级** - 适合为每个具体定义指定精确词性
3. **灵活组合** - 支持不同层级的不同选择模式

## 🔧 技术实现

### 词性选项定义

```typescript
const PARTS_OF_SPEECH_OPTIONS = [
    '名词',
    '动词',
    '形容词',
    '副词',
    '介词',
    '代词',
    '连词',
    '感叹词',
    '助动词',
    '情态动词',
    '数词',
    '冠词',
    '不定式',
    '动名词',
    '分词',
];
```

### 多选逻辑

```typescript
// 添加词性
const currentTypes = form.partsOfSpeech
    .split(',')
    .map((t) => t.trim())
    .filter((t) => t !== '');
currentTypes.push(option);
setForm({
    ...form,
    partsOfSpeech: currentTypes.join(','),
});

// 移除词性
const types = form.partsOfSpeech
    .split(',')
    .map((t) => t.trim())
    .filter((t) => t !== option);
setForm({
    ...form,
    partsOfSpeech: types.join(','),
});
```

### 单选下拉菜单

```tsx
<select
    value={part.type}
    onChange={(e) => {
        const content = [...form.content];
        content[partIndex].type = e.target.value;
        setForm({ ...form, content });
    }}>
    <option value="">请选择词性</option>
    {PARTS_OF_SPEECH_OPTIONS.map((option) => (
        <option
            key={option}
            value={option}>
            {option}
        </option>
    ))}
</select>
```

## 📱 界面设计

### 视觉层次

-   **已选标签** - 蓝色背景，白色文字，圆角设计
-   **可选按钮** - 白色背景，边框样式，hover 效果
-   **选中状态** - 蓝色背景 + "✓" 标记
-   **移除按钮** - "×" 符号，hover 显示

### 响应式设计

-   **自适应布局** - 选项按钮自动换行
-   **触控友好** - 按钮大小适合点击操作
-   **清晰对比** - 选中/未选中状态对比明显

## 🚀 使用场景

### 场景 1: 创建新单词

1. 在词性概述中快速选择主要词性（如：名词,动词）
2. 在详细内容中为每个定义选择具体词性
3. 保存时自动统一格式

### 场景 2: 编辑现有单词

1. 系统自动解析现有词性并在界面中标记
2. 用户可以快速添加或移除词性
3. 保持数据一致性

### 场景 3: 批量管理

1. 标准化的词性选择确保数据质量
2. 便于后续的筛选和统计分析
3. 提高数据录入效率
