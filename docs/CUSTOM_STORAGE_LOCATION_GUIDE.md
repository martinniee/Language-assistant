# 自定义存储位置功能文档

## 🎯 功能概述

Language Assistant 插件现在支持自定义 words.md 文件的存储位置，提供更好的隐私保护和文件组织能力。新增的**智能自动补全功能**让路径选择变得更加便捷。

## ✨ 主要特性

### 🔒 隐私保护

-   **自定义路径**：可将单词文件存储在任意位置
-   **隐藏文件夹**：支持点开头的隐藏文件夹（如 `.hidden/`）
-   **深层目录**：支持多级目录结构（如 `documents/language/words.md`）

### 🚀 智能自动补全 (NEW!)

-   **实时建议**：输入时显示文件和文件夹建议
-   **键盘导航**：使用方向键选择，回车确认
-   **智能过滤**：自动筛选 .md 文件，优先显示匹配项
-   **状态显示**：显示文件是否存在（✓ 存在 / + 新建）
-   **高亮匹配**：匹配的文字高亮显示

### 🛠️ 配置选项

-   **图形化设置**：通过插件设置页面轻松配置
-   **实时验证**：输入时自动验证路径格式
-   **即时生效**：设置更改后立即应用到所有窗口

### 🔄 智能管理

-   **自动创建**：不存在的文件夹会自动创建
-   **文件检查**：可检查目标文件是否存在
-   **路径重置**：一键重置为默认设置

## 📂 使用方法

### 1. 打开设置

1. 打开 Obsidian 设置
2. 找到 "Community plugins" → "Language Assistant"
3. 点击设置图标

### 2. 使用自动补全配置存储路径

1. 在 "📁 存储文件路径" 输入框中开始输入
2. 系统会自动显示匹配的建议：
    - **现有文件**：显示已存在的 .md 文件
    - **文件夹**：显示可用文件夹 + 建议文件名
    - **新文件**：基于输入自动添加 .md 扩展名
3. 使用键盘操作：
    - **↑/↓** 选择建议项
    - **Enter** 确认选择
    - **Esc** 关闭建议列表
4. 也可以直接点击建议项进行选择
5. 路径会自动验证并保存

### 3. 路径示例

#### 基本存储

```
words.md                    # 根目录（默认）
vocabulary.md               # 根目录自定义名称
```

#### 隐私保护

```
private/words.md           # 私有文件夹
.hidden/vocabulary.md      # 隐藏文件夹
personal/.secret/words.md  # 多级隐藏
```

#### 分类组织

```
documents/language/english-words.md    # 按语言分类
study/vocabulary/my-words.md          # 按用途分类
backup/words/main.md                  # 备份目录
```

```typescript
const DEFAULT_SETTINGS = {
    wordsFilePath: 'words.md', // 默认在根目录

```

### 动态路径更新

```typescript
// 设置更改时自动更新所有视图
this.plugin.app.workspace
    .getLeavesOfType(VIEW_TYPE_WORD_MANAGER)
    .forEach((leaf) => {
        if (leaf.view instanceof WordManagerView) {
            leaf.view.updateStoragePath(newPath);
        }
    });
```

## 🎮 自动补全功能详解

### 功能特性

-   **智能搜索**：实时扫描库中的文件和文件夹
-   **多种建议**：包括现有文件、文件夹路径和自动补全
-   **快速选择**：支持键盘和鼠标操作
-   **视觉反馈**：高亮匹配文字和状态指示器

### 建议类型

1. **现有 .md 文件**：直接选择已存在的 Markdown 文件
2. **文件夹建议**：在文件夹中创建新的 words.md 文件
3. **自动补全**：为输入自动添加 .md 扩展名
4. **直接路径**：支持完整路径输入

### 键盘快捷键

-   **↑/↓ 箭头键**：在建议列表中导航
-   **Enter**：选择当前高亮的建议
-   **Esc**：关闭建议列表
-   **Tab**：（可选）快速接受第一个建议

### 状态指示器

-   **✓ 存在**：文件已存在，将使用现有文件
-   **+ 新建**：文件不存在，将创建新文件

### 使用技巧

1. **模糊搜索**：输入部分文件名即可找到匹配项
2. **文件夹优先**：想在特定文件夹中创建文件时，先输入文件夹名
3. **快速创建**：直接输入完整路径名，系统会自动补全
4. **批量选择**：从建议中快速选择最佳位置

## 🚨 重要注意事项

### ⚠️ 数据迁移

-   更改路径 **不会自动迁移** 现有数据
-   如需迁移，请 **手动复制** 文件到新位置
-   建议先 **备份** 现有单词数据

### 📁 文件夹创建

-   不存在的文件夹会 **自动创建**
-   深层路径会 **递归创建** 所有必要的父文件夹
-   权限不足时会显示 **详细错误信息**

### 🔄 设置同步

-   设置保存在 Obsidian 的插件数据中
-   不同设备间需要 **手动同步** 设置
-   建议在每台设备上 **单独配置** 路径

## 🆘 故障排除

### 问题：文件不存在

**解决方案**：

1. 使用 "🔍 检查文件" 按钮确认状态
2. 文件不存在是正常的，会在添加第一个单词时自动创建
3. 如果需要立即创建，可以先添加一个临时单词

### 问题：权限不足

**解决方案**：

1. 检查目标文件夹的写入权限
2. 尝试使用相对路径而非绝对路径
3. 选择 vault 内的路径

### 问题：设置不生效

**解决方案**：

1. 关闭并重新打开单词管理页面
2. 重启 Obsidian 应用
3. 检查控制台是否有错误信息
