# 间隔重复学习系统 (SRS) - 功能文档

## 🧠 系统概述

本项目实现了基于 **Anki SM2 算法** 的间隔重复学习系统，旨在通过科学的复习间隔来提高单词记忆效果。

## ✨ 核心功能

### 1. 🏗️ 数据结构扩展

#### WordMetadata 新增字段

```typescript
interface WordMetadata {
    // 原有字段
    id: string;
    queryCount?: number;
    createBy?: string;
    lastUpdate?: string;

    // 新增SRS字段
    srsLevel?: number; // SRS等级 (0-8，0为新卡片)
    nextReviewDate?: string; // 下次复习日期 (ISO 8601)
    lastReviewDate?: string; // 上次复习日期
    reviewCount?: number; // 总复习次数
    correctCount?: number; // 正确次数
    ease?: number; // 难度因子 (1.3-2.5，默认2.5)
    interval?: number; // 当前间隔天数
}
```

### 2. 🎯 SM2 学习算法

#### 复习结果类型

-   **陌生** (AGAIN): 完全不记得，重新开始学习
-   **模糊** (HARD): 记得但困难，增加复习频率
-   **熟悉** (GOOD): 记得且容易，正常间隔增长
-   **简单** (EASY): 非常容易，大幅增加间隔

#### 算法特点

-   **自适应难度**: 根据回答质量动态调整难度因子
-   **科学间隔**: 基于遗忘曲线的最优复习时间
-   **个性化学习**: 每个单词独立的学习进度追踪

## 🔄 学习流程

### 第一步：开始学习

1. 进入 "间隔学习" 模块
2. 查看今日待学习单词数量
3. 设置学习数量上限 (10/20/50/100)
4. 点击 "开始学习" 按钮

### 第二步：学习过程

1. **显示单词**: 展示单词、发音、分类信息
2. **思考回忆**: 用户尝试回忆单词含义
3. **查看答案**: 点击 "显示答案" 查看详细释义
4. **评估掌握度**: 选择 陌生/模糊/熟悉/简单

### 第三步：算法计算

1. **更新数据**: 系统自动更新 SRS 相关字段
2. **计算间隔**: 根据 SM2 算法计算下次复习时间
3. **调整难度**: 动态调整单词的难度因子
4. **保存进度**: 实时保存学习数据

### 第四步：完成总结

1. **展示统计**: 显示本次学习的统计数据
2. **正确率分析**: 计算并显示学习效果
3. **耗时统计**: 记录学习时长
4. **鼓励提示**: 给出积极的学习反馈

## 🎯 算法详解

### SM2 算法核心

```typescript
// 难度因子计算
newEase = Math.max(1.3, Math.min(2.5, currentEase + easeModifier));

// 间隔计算
newInterval = Math.round(currentInterval * newEase);

// 下次复习时间
nextReviewDate = new Date(Date.now() + newInterval * 24 * 60 * 60 * 1000);
```

### 学习阶段划分

1. **新卡片阶段** (Level 0): 初次学习，短间隔复习
2. **学习阶段** (Level 1): 正在记忆，逐步增加间隔
3. **毕业阶段** (Level ≥2): 已掌握，长间隔复习

### 容错机制

-   **数据验证**: 确保 SRS 字段的合理性
-   **降级保护**: 避免过度惩罚学习者
-   **上限控制**: 防止间隔过长或过短
