# 🎯 智能选择器使用指南

## 📖 快速上手

### **分类选择示例**

```
场景：添加英语单词 "hello"

1. 首次使用 - 创建新分类：
   分类: [选择已有分类 ▼] 或 [输入: "日常用语"]

2. 后续使用 - 选择已有：
   分类: [日常用语 ▼] 或 [新建分类]
```

### **标签管理示例**

```
场景：为单词添加多个标签

1. 查看已选标签区域：
   ┌─────────────────────────────┐
   │ 请选择或添加标签             │
   └─────────────────────────────┘

2. 从已有标签中选择：
   📋 从已有标签中选择:
   [+ 问候语] [+ 基础词汇] [+ 口语]

3. 点击 [+ 问候语] 后：
   ┌─────────────────────────────┐
   │ [问候语 ×]                  │
   └─────────────────────────────┘

4. 继续选择或添加新标签：
   [+ 基础词汇] [+ 口语]  (问候语已隐藏)

   ✨ 添加新标签:
   [输入新标签名称] [添加标签]

5. 最终结果：
   ┌─────────────────────────────┐
   │ [问候语 ×] [基础词汇 ×] [常用 ×] │
   └─────────────────────────────┘
```

## 🎯 操作技巧

### **快捷键操作**

-   **回车键**: 在新标签输入框中按回车快速添加
-   **点击 ×**: 快速删除不需要的标签
-   **悬停查看**: 鼠标悬停查看添加/删除提示

### **最佳实践**

1. **分类命名**: 使用简短、清晰的分类名称
2. **标签规范**: 避免创建语义相近的重复标签
3. **批量操作**: 先选择已有标签，再添加新标签
4. **定期整理**: 利用选择器了解现有标签结构
